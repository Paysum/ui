# Paysum UI

Open-source interface for [Paysum](https://paysum.io). The same buttons, cards, and numbers used on checkout, store themes, and the dashboard. Each component is available in Svelte and React.

```bash
npm install
npm run dev
```

Open http://localhost:5173.

Copy a file from `src/lib/components` (Svelte) or `registry/react` (React), plus `src/lib/utils.ts` and the tokens in `src/app.css`. MIT licensed.
